# Website manifest

- `app/[locale]/layout.tsx`: localized layout and SEO metadata
- `app/[locale]/page.tsx`: landing page
- `components/`: navigation, hero, statistics, features, comparison, download availability, FAQ and footer
- `messages/en.json`, `messages/de.json`: localized content
- `i18n/`, `middleware.ts`: locale routing
- `tests/`: production-site smoke tests
- `../.github/workflows/website.yml`: build and deployment

See `README.md` for development and verification instructions.
